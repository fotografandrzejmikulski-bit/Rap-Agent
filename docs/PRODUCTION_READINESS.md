# Ω∞ Production Readiness Contract

## Definition of done

The system is considered finished only when all of the following are true:

- one canonical runtime path is authoritative;
- creator identity is configuration-driven;
- psychic state survives restart and elapsed time;
- memory has durable persistence and associative retrieval;
- uncertain recollection cannot silently become canon;
- every forge run has idempotent request handling and durable evidence;
- the adversarial layer operates before finalization;
- identity and originality are veto dimensions;
- quality decisions are policy-driven rather than based only on a self-reported score;
- CI executes integrity checks and tests on every change;
- scheduled wake-ups are serialized to avoid state corruption;
- the Git repository is treated as versioned persistence, not as the real-time database;
- API boundaries have explicit payload and size limits;
- the system never claims that computational continuity is literal consciousness.

## Non-goals

Ω∞ does not claim sentience, subjective experience, or a scientifically validated model of human memory. Terms such as consciousness, synapse, wandering thought and psychic tensor are engineering metaphors for persistent state dynamics.

## Final quality doctrine

A track is not accepted because a model says it is good. Acceptance requires deterministic policy gates plus adversarial evidence. Score inflation, judge flattering and cosmetic word substitution are considered failures of the production process.
